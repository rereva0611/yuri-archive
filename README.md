# ReReva's Yuri Archive

一个不知名百合豚的馆藏。

用于记录、整理和分享百合（Yuri）作品的个人档案网站。

**[在线访问](https://rereva0611.github.io/yuri-archive/)**

## 功能

- **作品档案**：收录作品基本信息、封面、标签及评价。
- **检索与筛选**：支持多语言标题搜索、分类筛选和排序。
- **个人评价**：记录阅读状态、个人评分、喜爱程度及文字评语。
- **社区评分**：获取 Bangumi 和 AniList 评分。
- **资源索引**：整理个人推荐的 ACG 网站与工具。

## 技术

- HTML / CSS / JavaScript
- JSON / Markdown
- GitHub Pages

## 本地运行

```bash
git clone https://github.com/rereva0611/yuri-archive.git
cd yuri-archive
python3 -m http.server 8000
```

访问 `http://localhost:8000`。
